# CJ Walker · Portfolio

Static site (no build step) for GitHub Pages.

- `index.html` holds everything. Design tokens live at the top of the `<style>` block.
- **Add a UI kit:** copy one `[data-kit="..."]` light + dark token block in the CSS, then add an entry to `KITS` in the script at the bottom.
- `assets/` holds screenshots made with sample data (no real customer info).

Publish: Settings → Pages → Deploy from branch → `main` / root.
